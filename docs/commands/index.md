# Skills (Slash Commands)

A guide to the SDD skills for Claude Code.

## Overview

When you run `sdd init`, 30 English SDD workflow skills are automatically created under `.claude/skills/sdd-*/SKILL.md`. Claude Code exposes each skill as a slash command, so you invoke them as `/sdd-start`, `/sdd-spec`, and so on (kebab-case).

- **30 sdd-* skills** in `.claude/skills/sdd-*/` — invoked as `/sdd-<name>`
- `.claude/commands/` is **not** generated by default. Claude Code merges custom commands into skills, so skills are the supported format.
- To additionally write the legacy Korean dot-notation commands (`.claude/commands/sdd.*.md`), run `sdd init --legacy-commands`.
- Use `--no-skills` to skip skill generation.

### Skill Frontmatter

Each skill's `SKILL.md` uses these frontmatter fields:

| Field | Applied to |
|-------|-----------|
| `context: fork` | 7 analysis/domain skills (`sdd-analyze`, `sdd-impact`, `sdd-report`, `sdd-research`, `sdd-reverse`, `sdd-search`, `sdd-sync`) |
| `disable-model-invocation: true` | 5 utility skills (`sdd-chat`, `sdd-cicd`, `sdd-guide`, `sdd-migrate`, `sdd-watch`) — only you can invoke them |
| `argument-hint` | Skills that take arguments |
| `allowed-tools` | All sdd-* skills — least-privilege patterns (e.g., `Bash(sdd validate*)`) |

## Usage

Enter skills starting with a slash in Claude Code:

```
/sdd-start
```

When arguments are needed:

```
/sdd-spec user authentication feature
```

## Examples

### Reverse Engineering Workflow

Extract SDD specs from legacy code. The AI reads the code and writes drafts; the CLI scans, validates, reviews, and finalizes:

Run `/sdd-reverse`; it guides you through scanning the project, drafting specs from the code, reviewing the drafts, and finalizing them. See [/sdd-reverse](/commands/sdd-reverse) for details.

```
/sdd-reverse                              # AI-driven: scan, read code, write drafts
sdd validate .sdd/.reverse-drafts         # Validate drafts
sdd reverse review --list                 # Review drafts
sdd reverse review <ref> --approve        # Approve (after confirmation)
sdd reverse finalize                      # Move approved drafts to .sdd/specs/
```

### Domain System

Logically group large projects:

```
/sdd-domain create auth        # Create domain
/sdd-domain graph              # Dependency graph
/sdd-context set auth payment  # Set working context
```
